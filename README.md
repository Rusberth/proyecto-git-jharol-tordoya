
# Gimnasio Titán - Práctica Git y GitHub

## Integrantes

- Jharol Tordoya

## Descripción

Sitio web de un gimnasio. Muestra los planes de membresía con sus precios, el horario
de clases grupales y un formulario de inscripción. El proyecto se desarrolló con Git y
GitHub: cada parte se trabajó en una rama distinta y se integró a `main` mediante
Pull Requests.

| Rama | Rol | Archivo |
|------|-----|---------|
| `feature/html-estructura` | Integrante A | `index.html` |
| `feature/estilos-css` | Integrante B | `style.css` |
| `feature/funcionalidad-js` | Integrante C | `script.js` |
| `docs/readme` | Documentación | `README.md` |
| `fix/titulo-readme` | Resolución de conflicto | `README.md` |

## Tecnologías

- HTML
- CSS
- JavaScript

## Funcionalidades

- Validación del formulario de inscripción (nombre, correo, celular y plan).
- Filtro de clases por tipo: cardio, fuerza y flexibilidad.
- Botón "Elegir plan" que selecciona el plan en el formulario automáticamente.
- Menú desplegable para celulares (mostrar/ocultar).

## Cómo ver el proyecto

Abrir el archivo `index.html` en el navegador.
